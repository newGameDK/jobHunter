Tjekker lokal scraper…

Lokal scraper er ikke aktiv. For at søge jobs skal du starte den lokale helper-app på din PC:

  1. Sørg for Python 3.8+ er installeret
  2. Åbn en terminal i local_scraper/ mappen
  3. Installer afhængigheder: pip install -r requirements.txt
  4. Start scraper: python helper.py
  5. Klik Tjek igen herunder

Scraperens port kan ændres i js/config.js (LOCAL_SCRAPER_URL).

Åbn jobindex.dk i din browser, søg som du ønsker, kopiér URL'en og indsæt den her.
